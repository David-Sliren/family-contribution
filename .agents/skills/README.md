# Skills del proyecto

Estas skills contienen convenciones y flujos reutilizables por cualquier agente que trabaje en este repositorio.

- `git-commit-convention/SKILL.md`: formato, agrupación y preparación de commits.
- `dashboard-filters-pagination/SKILL.md`: filtros y paginación del dashboard.
- `plan-empirico/SKILL.md`: flujo para definir y ejecutar planes de trabajo.
- `video-usuario/SKILL.md`: creación de un video de la serie de usuarios (`/video-usuario`) desde sus guiones en `docs/usuarios/`.

Lee la skill correspondiente antes de realizar el trabajo que describe. Las copias de `.opencode/skills/` se mantienen para compatibilidad con OpenCode.
